Speed Tips

Four habits that save 20 minutes per video.

1
Export Templates First

Build Opening Sting + End Card before touching raw footage. Saves 5 minutes per video.

2
Duplicate Projects

Edit Video 1 fully, then File → Duplicate Project. All timings and placements copy over. Swap footage only.

3
Auto Captions

Text → Auto Captions → English. Fix name spellings: Ryley, Rykiel, INITIUM.

4
Master Project

Save one project with all templates placed but no footage. Duplicate this for every future video.
