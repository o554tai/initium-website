## Step 5: Set Up Conversion Tracking

After the Pixel is installed and verified:

1. In Events Manager, click **“Add Events”** → **From the Pixel**
2. Select **“Track New Button Click”**
3. Navigate to your landing page in the preview
4. Click the **“Get VVIP Access”** button
5. Name the event: **Lead**
6. This tracks every form submission as a conversion
